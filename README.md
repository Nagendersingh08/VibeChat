# VibeChat

VibeChat is a MERN-style real-time chat app with a React/Vite client and an Express/Socket.IO server.

## Project Structure

```text
VibeChat/
  client/              React frontend
    src/
      assets/          Images, logos, and icons used by the UI
      components/      Reusable UI pieces like chat panels and dialogs
      context/         React context providers and context values
      lib/             Client helper utilities
      pages/           Route-level pages
      App.jsx          App routes
      main.jsx         React entry point
    public/            Static files served by Vite
    package.json       Client scripts and dependencies

  server/              Express backend
    controllers/       Request handlers
    lib/               Database, Cloudinary, and utility setup
    middleware/        Auth middleware
    models/            Mongoose models
    routes/            API route definitions
    server.js          Server and Socket.IO entry point
    package.json       Server scripts and dependencies
```

## Common Commands

Run these from the matching folder:

```bash
cd client
npm run dev
npm run build
npm run lint
```

```bash
cd server
npm run server
```

`client/dist` is generated by `npm run build`, so it can be deleted and rebuilt whenever needed.
