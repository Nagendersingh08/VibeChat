# VibeChat Client

This folder contains the React frontend for VibeChat.

## Folder Guide

```text
src/
  assets/        App images, icons, and logos
  components/    Reusable UI components
  context/       Auth and chat React context providers
  lib/           Small client utilities
  pages/         Login, home, and profile pages
  App.jsx        Route setup
  main.jsx       React app bootstrap
```

## Commands

```bash
npm run dev
npm run build
npm run lint
```
